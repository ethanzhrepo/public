The app is signed with a Developer ID certificate and notarized by Apple. Open the DMG and drag Voxrill to Applications. To check the download:

```sh
shasum -a 256 -c Voxrill-1.2.0.dmg.sha256
```

Versions 1.0.0 and 1.1.0 cannot download Whisper speech models on a Mac that has none yet. Please use 1.1.1 or later.

The downloaded version does not update itself yet. New versions are posted here and on voxrill.com.

## 下载

适用于搭载 Apple Silicon、运行 macOS 15 或更新版本的 Mac。应用已使用 Developer ID 签名并通过 Apple 公证。打开 DMG，把 Voxrill 拖到“应用程序”文件夹即可。下载版暂不支持自动更新，新版本会发布在这里和 voxrill.com。1.0.0 和 1.1.0 在新 Mac 上无法下载 Whisper 语音模型，请使用 1.1.1 或更新版本。
